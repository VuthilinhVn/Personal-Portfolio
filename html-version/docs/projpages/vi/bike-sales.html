Dashboard Bán Xe Đạp

Mục tiêu:

Dự án phân tích hành vi mua xe đạp của 1.000 khách hàng, nhằm xác định những yếu tố nhân khẩu học : giới tính, độ tuổi, thu nhập, tình trạng hôn nhân, khu vực và khoảng cách đi làm : có ảnh hưởng mạnh nhất đến quyết định mua xe. Sản phẩm cuối là một dashboard Excel tương tác đầy đủ với slicer, pivot chart và pivot table, để người xem tự lọc và khám phá dữ liệu.

Tải file Excel

Tổng quan dữ liệu:

Số khách hàng

1.000

Thuộc tính phân tích

13

Khu vực

Europe / Pacific / North America

Phương pháp:

Bước 1 : Làm sạch dữ liệu (Power Query)

  • Loại bỏ ID trùng lặp trong sheet bike_buyers gốc.
  • Chuẩn hóa Marital Status (M / S → Married / Single) và Gender (M / F → Male / Female).
  • Thay null trong các cột số, ép kiểu lại cho Income / Age / Cars / Children.
  • Bổ sung cột Age Brackets (Adolescent 12-35, Adult 35-59, Old >60) để phân tích theo nhóm tuổi.

Bước 2 : Pivot Table

Ba pivot table được xây dựng trên working sheet đã làm sạch:

  • Thu nhập trung bình theo Giới tính & Quyết định mua xe : xem khách thu nhập cao có mua xe nhiều hơn không.
  • Nhóm tuổi vs Quyết định mua xe : xem nhóm tuổi nào mua xe nhiều nhất.
  • Khoảng cách đi làm vs Quyết định mua xe : kiểm tra commute distance có phải yếu tố dự báo không.

Bước 3 : Dashboard tương tác

Các pivot table được chuyển thành pivot chart (bar chart cho Income, line chart cho Age Brackets và Commute Distance). Slicer cho Marital Status, Region và Education được gắn lên đầu dashboard để người xem lọc đồng thời mọi biểu đồ. Kết quả là một dashboard 1-trang phản hồi tức thì theo thao tác : giống hệt trải nghiệm khi mở file trong Excel.

Dashboard tương tác:

File workbook bên dưới là file thực. Click các tab sheet ở dưới cùng để chuyển giữa bike_buyers (dữ liệu thô), working sheet (đã làm sạch), pivot table và dashboard. Dùng các slicer trong tab dashboard để lọc biểu đồ.

Kết luận:

Dashboard cho thấy lượng mua xe tập trung ở nhóm Adolescent 12-35 và Adult 35-59, khách có thu nhập trung bình cao, và khách có khoảng cách đi làm ngắn (0-5 dặm) có khả năng mua xe cao hơn rõ rệt.
