自行车销售仪表板

目标：

本项目分析 1,000 位自行车购买者的购买行为，找出对购买决定影响最大的人口统计因素 —— 性别、年龄、收入、婚姻状况、地区和通勤距离。最终交付物是一个带切片器、数据透视图和数据透视表的 完全交互式 Excel 仪表板，观看者可以自行筛选并探索数据。

方法：

第 1 阶段 —— 数据清洗 (Power Query)

  • 移除原始 bike_buyers 工作表中的重复 ID。
  • 标准化 Marital Status (M / S → Married / Single) 和 Gender (M / F → Male / Female)。
  • 替换数值列中的空值，并重新定义 Income / Age / Cars / Children 的数据类型。
  • 新增 Age Brackets 列 (Adolescent 12-35, Adult 35-59, Old >60) 以便按年龄群分析。

第 2 阶段 —— 数据透视表

在清洗后的 working sheet 上构建了三张数据透视表：

  • 平均收入 × 性别 × 是否购买 —— 检验高收入客户是否更倾向购车。
  • 年龄段 × 是否购买 —— 找出购买量最高的年龄群。
  • 通勤距离 × 是否购买 —— 检验通勤距离是否为购买的预测因子。

第 3 阶段 —— 交互式仪表板

数据透视表被转换为数据透视图（收入为柱形图，年龄段和通勤距离为折线图）。在仪表板顶部添加了 Marital Status、Region 和 Education 切片器，可同时筛选所有图表。 最终是一个单页式仪表板，能实时响应操作 —— 与在 Excel 中打开文件的体验完全相同。

交互式仪表板：

下方嵌入的工作簿就是真实文件。点击底部的工作表标签可在 bike_buyers（原始数据）、working sheet（清洗后数据）、pivot table 和 dashboard 之间切换。在 dashboard 标签中使用切片器即可筛选图表。

注：嵌入内容从本站点的公开 GitHub Pages URL 加载。如果您在部署之前在本地 (file://) 预览此页面， Office Viewer 将为空白 —— 请使用上方的下载按钮，用 Excel 打开查看。

结论：

仪表板显示，自行车购买集中在 Adolescent 12-35 和 Adult 35-59 这两个年龄段， 购买者的平均收入高于未购买者，且通勤距离较短 (0-5 英里) 的客户购车意愿明显更高。 如果这是一个真实的营销活动，这些洞察可以用来指导营销预算的投放方向。
