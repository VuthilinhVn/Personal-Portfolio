Bike Sales Dashboard

Objective:

The goal of this project is to explore the purchase behavior of 1,000 bike-buyer profiles and identify which demographic factors — gender, age, income, marital status, region and commute distance — are most strongly associated with the decision to buy a bike. The end deliverable is a fully interactive Excel dashboard with slicers, pivot charts and pivot tables so the audience can filter and explore the data on their own.

Methodology:

Phase 1 — Data Cleaning (Power Query)

  • Removed duplicate IDs from the raw bike_buyers sheet.
  • Standardized Marital Status (M / S → Married / Single) and Gender (M / F → Male / Female).
  • Replaced null values in numeric columns and re-typed Income / Age / Cars / Children.
  • Added an Age Brackets column (Adolescent 12-35, Adult 35-59, Old >60) to enable age-cohort analysis.

Phase 2 — Pivot Tables

Three pivot tables were built on top of the cleaned working sheet:

  • Average Income by Gender & Purchased Bike — to test whether higher-earning customers buy bikes more often.
  • Customer Age Bracket vs Purchased Bike — to see which age cohort drives the most purchases.
  • Commute Distance vs Purchased Bike — to check whether commute distance is a predictor of bike purchase.

Phase 3 — Interactive Dashboard

The pivot tables were turned into pivot charts (bar chart for Income, line charts for Age Brackets and Commute Distance). Slicers for Marital Status, Region and Education were added on top so the viewer can filter all charts simultaneously. The result is a one-page dashboard that reacts in real time to user input — exactly the same experience as opening the file in Excel.

Conclusion:

The dashboard shows that bike purchases are concentrated in the Adolescent 12-35 and Adult 35-59 brackets, that buyers earn on average a higher income than non-buyers, and that customers with shorter commute distances (0-5 miles) are far more likely to buy a bike. These insights would inform where to focus marketing spend if this were a real campaign.
